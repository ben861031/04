# 公文逾期稽催管理系統 (Document Tracking System)

這是一個純前端執行的「公文逾期稽催管理系統」，透過瀏覽器即可將公文系統產出的清單進行匯入、過濾、重新排版與統計，幫助使用者快速辨識並追蹤逾期未歸檔的公文。本系統完全在本地端運行，兼具企業級介面的專業度與資料絕對的安全性。

## 核心系統特色

### 1. 現代化專業行政介面 (Professional UI)
- **頂部導覽列架構**：採用現代化企業軟體的頂部導覽列設計，將系統動作與資料區塊分離，視覺清爽無負擔。
- **外部系統無縫串聯**：導覽列左側內建「檔管作業」與「原系統稽催清冊」的快速連結，方便承辦人隨時切換回官方系統進行比對或後續作業，且皆採新分頁開啟，不干擾當前工作進度。
- **極簡嚴謹風格**：捨棄多餘的圖示與花俏圓角，以乾淨俐落的網格、收斂的色彩計畫，呈現正式系統應有的莊重與專業感。
- **完美對齊的排版細節**：專為公事信件與報表設計，所有產出的表格皆具備「固定列高 (50px)」與「完美對稱的欄寬配置」，確保標題與內文在 Outlook 或 Word 都能呈現 100% 精準的置中與對齊，展現極致專業度。

### 2. 雙軌資料匯入模式 (Data Import)
- **智慧匯入 (從剪貼簿貼上)**：無須下載 Excel！直接在舊有公文系統中反白複製表格，點擊「智慧匯入」後貼上，系統便能自動解析網頁表格並無縫轉換，大幅縮短作業時間。
- **全螢幕拖曳匯入 Excel**：將 Excel 檔案（`.xlsx`, `.xls`）拖曳至網頁任意角落，即可瞬間完成解析匯入。

### 3. 一鍵生成 Outlook 信件與聯絡人自動化 (Email Automation)
- **聯絡人與副本設定**：可於頂端「信件聯絡人設定」中，為每一個部門綁定專屬的「行政聯絡人 Email (To)」，並可設定全域「固定副本收件者 (Cc)」。系統會自動記憶於您的瀏覽器中，永久有效。
- **一鍵寄發 Outlook**：只要選擇特定部門，點擊「寄發 Outlook」，系統會在一秒內自動產出 `.eml` 檔案。打開後，**收件者、副本、主旨、問候語與排版精美的稽催表格**全數自動填妥，完美解決中文字元編碼 (Mojibake) 與排版跑位問題，無須任何手動貼上！
- **智慧信件複製中心**：若您想手動複製貼上，點擊「複製查詢結果 > 複製信件範本」，系統將開啟「信件複製中心」，提供**四步防呆複製流程**：
  - 第一步：複製收件者 (To)
  - 第二步：複製副本收件者 (Cc)
  - 第三步：複製信件主旨
  - 第四步：複製信件內文
  *(💡 貼心設計：若該部門尚未設定信箱，系統會自動切換為「無設定 (點擊跳過)」，引導您順暢完成作業而不會卡關。)*

### 4. 智慧分類與彈性篩選
- **自動化公文判斷**：系統根據處理天數差距，自動預判「收文」或「發文」（預設判斷基準為 **7天**，可自訂調整）。
- **強制手動校正**：若系統判斷有誤，可直接透過下拉選單手動切換最終類型，系統會自動記憶您的修改。
- **多維度檢視**：支援部門分頁切換、收發文快速過濾，以及支援關鍵字的全局搜尋功能。

### 5. 報表輸出與分享
- **即時數據儀表板**：頂部儀表板即時統計當下條件的收/發文逾期總數。
- **一鍵寄發 Outlook**：最快、最完整的稽催通知解決方案。
- **一鍵複製表格**：點擊「複製查詢結果 > 複製表格」，直接至 Word 或 Line 按下 `Ctrl+V`，即可貼上格式完美的稽催表格。
- **動態匯出 Word**：提供標準化的 `.doc` 書面報表（含公司抬頭）。匯出時，檔名將自動套用您所選擇的部門與當天日期（例如：`稽催清冊_水利部_20260724.doc`）。
- **匯出 Excel**：適合留存數位檔案備查。

## 🚀 使用說明

由於本系統為純前端架構，**不需要架設伺服器**，只要有瀏覽器即可開始作業：

### 步驟一：開啟系統
使用瀏覽器（推薦 Google Chrome 或 Microsoft Edge）雙擊開啟 `index.html`。

### 步驟二：匯入資料
位於畫面右上角，您可以選擇兩種匯入方式：
1. **[匯入 Excel]**：點選按鈕或將檔案直接拖曳進網頁畫面中。
2. **[智慧匯入]**：若不想下載檔案，可直接複製原系統的表格，點擊此按鈕後在視窗中貼上，讓系統自動為您解析。
> 系統會於導覽列顯示「最後載入檔案」的狀態，並在您下次開啟時自動還原資料。

### 步驟三：條件設定與操作
- 確認「**稽催基準日**」（預設為今日），系統會依此自動計算「已逾期天數」。
- 利用工具列的「**公文類型**」、「**部門分頁**」與「**關鍵字搜尋**」來聚焦需要追蹤的案件。
- 檢查「**最終類型**」欄位，若判斷不符，可直接點擊下拉選單手動覆蓋。
- 點擊上方「**信件聯絡人設定**」為各部門設置專屬的行政聯絡人 (To) 以及全域副本 (Cc)。

### 步驟四：輸出與匯出
確認無誤後，使用右上方的按鈕產出結果：
- **[寄發 Outlook]**：**(推薦)** 直接產出包含完整收件者與內文的 `.eml` 郵件檔，開啟後即可發送。
- **[複製查詢結果]**：
  - **複製表格**：僅複製資料清單。
  - **複製信件範本**：開啟「信件複製中心」，透過四步引導複製收件人、主旨與內文。
- **[匯出 Word]**：適合列印成書面報告（自動附上標準抬頭，檔名動態生成）。
- **[匯出 Excel]**：適合留存數位檔案備查。

### 🧹 重置系統
若要處理下一批全新的資料，請點擊 **[清除資料]** 以清空畫面與暫存，避免新舊資料混淆。
